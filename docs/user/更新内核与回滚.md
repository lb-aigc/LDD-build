# LDD 0.2.0：更新内核、图片和视频分析

## 先说结论

LDD 桌面外壳和 DeepSeek Harness 内核现在分开更新。

- Harness 有新版本：在 LDD 的“内核更新”页面下载安装，不需要重新安装 LDD，也不需要手工复制文件。
- LDD 自身界面或桌面功能有新版本：仍会发布新的 `LDD-Setup-*.exe`。
- 更新失败：LDD 不覆盖正在运行的内核，会恢复上一可用版本；如果还没有外部旧版本，则恢复安装包内的 Fallback。

## 在线更新 Harness

1. 打开 LDD 的“帮助 → Harness 内核更新”。
2. 点击“检查更新”。
3. 有新版本时点击“下载新内核”。
4. LDD 会校验官方包名、精确版本、官方注册地址和 SHA-512，再安装到独立版本目录。
5. 点击“切换到新内核”后，LDD 先用空白 Profile 启动候选，再用当前 Profile 的隔离副本启动候选；两轮都会检查 Web、API、文本／视觉模型目录、视频工具和 Skill。
6. 两轮健康检查通过后，LDD 才备份真实 Profile、停止当前进程并启动候选。只有候选保持正常，版本指针才会提交。

在线更新不会覆盖 Harness profile、会话、API 配置或用户插件。

## 使用离线更新包

离线包扩展名为 `.lddruntime`。在故障恢复页点击“导入离线内核包”，选择文件即可。LDD 会自动完成以下工作：

- 防路径穿越解压；
- 校验 `runtime.json`、`checksums.sha256` 和每一个载荷文件；
- 检查 Windows x64、Node 主版本、最低 LDD 版本和内置视频插件；
- 安装到 `%LOCALAPPDATA%\LDD\runtime\versions\<Harness版本>`。

不需要把文件解压到程序目录，也不要手工替换 `app.asar`、`node_modules` 或 Fallback 文件夹。

官方离线包命名为 `deepseek-harness-<版本>-windows-x64.lddruntime`。

## 回滚

在“帮助 → 回滚到上一内核”中执行回滚。LDD 会先备份 Harness profile，然后切换到 `last-known-good`。第一次从安装包 Fallback 升级到外部版本时，Fallback 就是隐式的回滚目标。

内核目录与用户数据分开：

| 内容 | 默认位置 | 更新时处理方式 |
|---|---|---|
| 外部 Harness 版本 | `%LOCALAPPDATA%\LDD\runtime\versions` | 新版本写入新目录 |
| LDD Harness profile | `%APPDATA%\LDD\harness` | 保留并在切换前备份 |
| 安装包 Fallback | LDD 程序资源目录 | 只读，不被在线更新覆盖 |
| 旧版 profile | `%USERPROFILE%\.dsh` | 首次启动可复制验证，原目录不删除 |

## 图片大小限制

旧客户端的 5 MiB 前端限制已取消。LDD 提供两个模式：

- 普通模式：单张图片最高 20 MiB；
- 高级模式：单张图片最高 64 MiB。

高级模式不是无限制上传。单消息图片总量仍为 200 MiB，并保留最多 20 张、最高 64 MP、最长边 8192、规范化尺寸/体积以及压缩并发限制。最终能否被模型接受还取决于所选模型和 DeepSeek 服务端限制。

切换图片模式会重新生成 LDD 自己的托管 patch，不会覆盖用户的 `cordis.patch.yml`。

## 视频分析采用什么方案

当前方案固定为“本地抽帧后交给视觉模型”，而不是把原视频直接发给模型：

1. `ffprobe` 在本机读取元数据；
2. `ffmpeg` 在用户选择的时间范围内检测场景并抽帧；
3. 最多 9 帧组成一张带时间戳的 JPEG 联系表，并自适应压缩到安全大小；
4. 每批最多 4 张联系表交给配置的图片模型；
5. 返回按时间排序的观察结果、画面文字、证据时间戳、覆盖范围和警告。

默认视觉路由为 `deepseek-official/deepseek-v4-flash-vision-exp`。即使当前聊天使用纯文本模型，`analyze_video` 也可以单独调用这个视觉路由。视频必须位于当前工作区；超过 60 分钟的视频必须指定不超过 60 分钟的分析区间。

这样做的原因是当前接入契约明确支持图片输入，而没有把任意 MP4/MOV 作为原生 video 内容直接提交的稳定契约。以后只有模型目录声明 `video` 输入并且适配器实现该内容类型时，才适合增加“视频直传”路线。

## 卸载时的数据处理

手动卸载 LDD 时会询问是否同时删除 Harness 配置、会话、已下载内核与备份，默认选项为“否（保留）”。LDD 内部的升级卸载不会弹出该问题，也不会删除这些数据。

## 插件中心

插件中心使用 [GitHub 的 `dsh-plugin` Topic](https://github.com/topics/dsh-plugin)。第三方插件会在 Harness 进程中执行代码，安装前应检查源码、维护者、版本兼容范围和依赖。LDD 不会在内核更新时静默删除第三方插件。
