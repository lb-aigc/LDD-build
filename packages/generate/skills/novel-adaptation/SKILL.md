# 小说改编短剧 — 大纲 + 角色 + 剧本

把一本小说/故事改成 AI 短剧的**上游阶段**：先出改编大纲五件套，再拆角色档案，最后写逐集剧本。三个产物接力（大纲 → 角色 → 剧本），每层有硬质量门。

## 边界（不做的事）

- 不分镜、不写画面提示词、不出图、不配乐 → 那是 `novel-production`（下游）。
- 不写视频生成提示词 → 那是 `video-director`。
- 不改大纲结构（砍线合人只在大纲阶段做）。

## 阶段一：改编大纲

**必问参数**（缺了不开工，一次问完别轮流盘问）：**总集数 × 单集时长**、**题材**（决定爽点类型，猜错整份废）。改编幅度默认「抽核」（忠实/抽核/借壳），告知即可；已有偏好（保哪个角色/哪场戏）默认无。

**人物表从原文拆**，分档：`lead`（主角组，男女主+主反派）/ `support`（重要配角）/ `functional`（功能性角色）。大纲定下的分档是下游角色层的清单，**下游不推翻**。

**输出骨架四块**：`adaptation`（改编策略 + 取舍，关键取舍附原文 evidence 片段）/ `characters`（分档 + 人物线 + 来源）/ `scenes`（主场景）/ `beats`（爽点分布）。**快版骨架先给用户拍板三件事**——砍了哪条线、合了哪些人、大爆点落在第几集——不点头不进分集。

**分集梗概**每批 ≤10 集，叙述体（出现引号对白就是越界）。

**质量门（14 道，逐条查）**：
- 主角组 1–5 人、重要配角 ≤10、功能性角色 ≤10
- 主场景数 = 4 + ⌈集数/10⌉，夹在 5–15（60 集 → 10）
- 叙事道具 ≤8 件；爽点间隔 ≤3 集无真空
- 第 1 集有钩子；大爆点不压最后一集
- 每集三栏齐全；三人同框有拆解；叙述体无对白；无失业角色/空转场景/零集道具

## 阶段二：角色档案

从原文拆每个角色的：**人物画像**（性情/说话方式/动机弧）、**形象提示词**（外貌，英文）、**音色提示词**（声线）。**本阶段不出图**（出图是 character-refs 的活，选模型/画风/画幅三件事这里答不了）。

- 有大纲的 `characters` 块就直接当角色清单，别重判谁重要；留空待填的是画像/形象/音色细节。
- 主角组内部可细分（男女主 vs 主反派），但**不推翻大纲分档**。
- 引文要逐字对原文（校验「引文是否逐字」）。

## 阶段三：逐集剧本

**核心铁律**：剧本管戏，分镜管拍。这层只有**集、场次、节拍流**，没有镜号；镜头是下游分镜的活。台词反复推翻重写时，绑上镜头会每改一句都重排镜头。

**每集写的东西**（结构化数据，不能写成散文）：
- **逐集时长预算**：一集三分钟就是三分钟，台词按 **4.5 字/秒**折算、动作按 **2.5 秒/拍**估时，写超写欠当场拦。
- **节拍流**（动作 ⇄ 台词）：每句台词是独立条目（说话人 + 台词 + 语气），每个动作是独立节拍——这是全部确定性检查的地基，混成散文喂不进 TTS/生成管线。
- **每场至少一个动作节拍**：纯对白的场是广播剧，AI 生成时没画面可写。
- **开场钩子 + 结尾悬念**：每集生死线。钩子不是标签是第一拍，必须落在全集**前 3 拍内**（冷开场）；结尾一拍必须是悬念。
- **爽点认领**：大纲说这集有大爆点，剧本必须有戏认领它——防止改丢。
- **上游对账**：场景/光照/道具对 art.json、角色对 outline.json。

**质量门（10 道）**：每集时长在目标 ±15% 内；单句台词 ≤35 字；说话人在本场人物里或标 `VO`；每集钩子悬念落纸；钩子具象在前 3 拍内兑现；每场至少一个动作节拍；动作叙述体不混引号台词；爽点认领；角色对账；场景/光照/道具对账。

**写戏四条最重的**：动作节拍只写常见动作（AI 见过千万次的；精巧动作生成必崩）；时长预算先于一切（三分钟约 50 个节拍）；台词口语、单句一口气、谁的话像谁；每集第 1 拍冷开场给钩子具象。**写超先砍动作节拍再压台词；写欠补戏不注水（加冲突不加寒暄）。**

每批 ≤3 集（剧本是改得最凶的一层，小批量出、快拍板）。
