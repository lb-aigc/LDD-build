# 短剧打戏引擎 — 构思先于画面 + 每镜有任务

把一场打斗写成可直投 Seedance 的分镜提示词。写打戏不是「描述一张图」，是「指挥一台有质量的摄影机、拍一场有完整物理因果的事件」——每个特效有材质和重量、每次发力有传导和回执、每镜有任务和机位、镜头本身会被震退。

## 动作强度三档（写前先定档）

- **R1 写实/格斗**：现代格斗、MMA、追车、枪战、暗杀、喜感打斗 → 写实路线。
- **R2 武侠**：刀剑对决、拳法、轻功、剑阵 → 武侠路线。
- **R3 玄幻/仙侠**：法术对轰、法相、万剑归宗、割草清场、群战 → 玄幻路线（特效最重）。

## 构思层先于画面层（先想「为什么打」再想「怎么拍」）

**底层设定四件套**：双方动机 / 强弱错位 / 赌注 / 战场环境变数。
**五段式节奏**：起 → 承 → 危 → 破 → 收。
**全局节奏规划**：节奏曲线 / 爆发点 ≤3 / 快切长镜配额 / 静默点。

## 八步写作脑（脑内执行，不输出）

1. **定全局契约**：风格技术栈 / 能量主色+对撞色 / 三层材质 / 战场几何锚点 / 节奏曲线。
2. **每镜派一个镜头任务**：证规模 / 证力量 / 证速度 / 证招式 / 证轨迹 / 证情绪（六选一）。
3. **据任务定机位**。
4. **写可发力的身体**：蹬地→转胯→腰→肩→手完整发力链。
5. **特效从身体/武器长出来**：三层材质 + 尺度四件套 + 生命周期（不是凭空贴光效）。
6. **写力的三张回执**：命中 / 受力 / 环境（+ 镜头受力）。
7. **有质量的运镜拍出因果**。
8. **反向锁死**：负面清单禁本镜最易崩的点。

## 逐镜成句

每个 2-3 秒节点熔成一条「镜头先动 → 人物在镜头里动 → 镜头再动 → 下一动作命中」的交替咬合流动长句。**禁关键词袋、禁竖线串、禁字段罗列**——输出全是自然分镜句，字段只存在于脑内。

## 出稿前自检

每镜自问：这镜任务是什么？观众站哪？特效什么材质、分几层、占画框多少、对照什么参照物？力从哪起、收到哪三张回执？镜头被什么事件推动？和上镜怎么接、给下镜留什么？

**五维交替检验**：类型 / 空间 / 景别 / 速度 / 特效，任一维连续 5 镜相同即违规。

**六问**：这镜几种独立动作 / 动作类型 ≤2 类 / 有没有起-爆-顿-收四拍 / 命中瞬间定住了吗 / 看得见身体重心吗 / 抽掉特效连得成武打吗。

## 硬规则

- **攻击轴线固定往返，禁止背后袭来**；站位/朝向/光源/攻击轴线不跳变（呼应短剧-locks 的连续性锁）。
- **Seedance 时间轴一律整数秒**（0-3秒/3-6秒），禁小数点、毫秒、冒号时码。
- **资产编号沿用「图N」**：有角色图就「顾玄晔 =@图1（外观严格参考图1）」，有图零外观、省 token 给特效。
- **双轨制**：同一打戏可出「修仙版 + 写实版」两套，投喂时按模型版本选。
