# 短剧制片 — 站位 + 美术资产 + 分镜

把「剧本」变成「可投喂视频模型的分镜」的**下游阶段**：先排开场站位，再定场景美术资产，最后逐镜切分。三个产物接力（站位 → 美术 → 分镜），直接对接视频生成。

## 边界（不做的事）

- 不写戏、不改台词（那是 novel-adaptation 的活）。
- 不出角色/道具设定图（角色图是 character-refs 的活）。
- 不做视频生成与剪辑合成；口型/唇形同步暂不管。
- **每个镜头最终要写成的 Seedance/H3 视频提示词细节，交给 `video-director`**（本 skill 只负责「切哪些镜、每个镜覆盖哪些节拍、构图量化」，不重复写提示词规则）。

## 阶段一：开场站位（每场一次）

**为什么要单独排**：短剧每段视频独立生成，各段自己决定谁坐哪；群戏长桌第一段会多出没名字的宾客、第三段有人穿了主角衣服。所以每场**第一段**的站位必须先定死，分镜照抄。

**每场交付**：认图结果（每个地点 4–20 件东西，只写图上真有的）/ 俯视平面 / 开场站位（谁开场就在、谁后来才进；坐站跟着剧本；主位、对立、孤立用位置说出来）/ 开场走位句。

**三条最重的**：
- **图里看不到的不写**——提示词里有、图上没有的东西，人坐上去每段都不一样。
- **后来才进来的人开场不在**。
- **剧本没写有别人就没有群演**，且只使用认出来的那些东西。

## 阶段二：场景美术资产（每场景一次）

给每个场景定：**场景锚点**（主视角图）、**光照状态**（不同时段的光，剧本写到没登记的光照状态要补）、**叙事道具**（≤8 件，长在场景里的东西）。道具归场景，不归角色（角色身上的配饰归 character-refs 细节图）。

## 阶段三：分镜（逐集切镜）

**核心机制：镜头认领节拍。** 每个镜头声明覆盖剧本某场的哪几个连续节拍（`sceneIndex` + `beats:[起,止]`），**镜头不许跨场次**（换景必换镜）。这让分镜和剧本的关系可机械对账：每个节拍被恰好一个镜头认领、顺序不乱。

**切镜铁律**：
- **单镜头 ≤15 秒**（AI 视频单段生成上限；长对话强制拆镜）。
- **台词装得下**：认领节拍的台词秒数 ≤ 镜头秒数（逐镜检查）。
- **先按剧情单元分段**（每段 9–15 秒、不跨场），**段内切 2–5 秒的分镜**（对话正反打、关键动作插特写、进场三件套）。
- **每个镜头写构图量化字段**：`blocking`（谁左谁右、间距）、焦距/机位/构图/视线落点/焦点/稳定性——不出分镜图时，这些是构图的全部来源。
- 分镜图提示词（`frame`）中文直呼角色名（给图像模型配合设定图出图）；镜头正文（`shot`）中文、通用身份、写这几秒发生什么；景别是枚举，中文景别词必须写进分镜图提示词。

**输出附带**：生成批次单（同场景+同光照的镜头归一批、共用环境参考图）+ 配音对齐单（每句台词对到镜号，TTS 音频贴到哪段）。

**画幅**：正式合同只接受 `16:9` 或 `9:16`，全部分镜图与下游生成图保持同一画幅；竖屏短剧明确 `9:16`。
