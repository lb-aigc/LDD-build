# 短剧投喂封装 — 六道闸门 + 素材接线单

分镜稿出来后，到这里变成**可直接复制到平台的投喂提示词**。这是**最后一关的质检与封装**：不改剧本、不改台词、不重新分镜、不定资产结构。

## 输出前六道闸门（每一份提示词出门前必过）

1. **节奏**：台词念得完吗（时长对得上）。
2. **台词时长**：逐句台词按语速折算，不超单段上限。
3. **字数**：不超模型单次上限（超限会被截断）。
4. **可投喂语义**：不写模型执行不了的交接话术。
5. **图片数量**：引用图不超平台单次上限。
6. **编号一致性 + 素材形态一致性**：图号不混用，形态声明与图号一致。

**台词完整性契约（治「格式全对、内容漏句」）**：本层**不得凭空丢失上游分镜稿的任何一句台词**——封装可以压动作行、并镜头、调字数，但台词是用户财产。投喂前对照上游分镜稿逐句核对；**发现缺失 = 回退上游补齐，不得在本层静默消化**。

## 素材编号统一「图N」

- ✅ 用 `图1`、`图2`、`图3`……
- ❌ 禁用 `@图片N` / `@ImageN` / `CH001` / `SC001` / `ST001` 等外部写法。
- 景别术语中文体系：特写/近景/中近景/中景/全景/远景/大远景/微距。
- 时间轴：总时长/画幅/分辨率/模式/任务类型**移到代码框外**，纯净提示词内不写平台参数。

## 素材形态（呼应 short-drama-locks 的 M 轴）

- **交付首行必写形态声明**（如 `> 素材形态：M1（编号占位 · 图号 N 个 · 接线单见文末）`）；未声明 = 形态未定，不得交付。
- **M1 必附《素材接线单》**（图号→类型→用途→你该挂哪张→不控制什么）——交付必备件，不是可选附件。
- **M0 稿件内不得出现任何图号**（图号槽位与形态声明互斥）。
- 禁止：索要图片作为继续条件 · 因缺图阻断交付 · 声称「与资产图册一致/已核验」而实际没见过图。

## 多段衔接策略

多段输出时，先出**相邻段边界推荐表**（相邻两段怎么接：末帧定格/换机位/空镜/技巧转场），再写提示词。

## 工程语言清洗

投喂稿里清掉工程语言（「如上所述」「镜头1-3」这类给协作看的备注），只留模型能执行的纯净描述与台词。

## 输出模式（A/B/C）

先给 2-5 行推荐，用户不指定则**默认 C 导演轨纯净版**（只留画面 + 台词 + 音效/配乐标注，去一切工程噪音）。
