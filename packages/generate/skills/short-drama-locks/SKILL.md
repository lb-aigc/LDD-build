# 短剧立项锁 — 六道前置锁 + 画风锁

动笔前的**硬门**：任何一道锁用户未指定 = 任务不开始，停下询问、把选项摆出来让他勾，**禁止默认跳过、禁止替用户推断**。

## 六道前置锁（每个任务第一步，同一锁定期内一次性锁完）

| 锁 | 选项 | 说明 |
|----|------|------|
| **〇·0 赛道** | ① 国内剧 / ② 海外剧 / ③ 解说叙事类 / ④ 其他 | 四选一；未指定唯一正确动作是停下问，禁止默认「国内剧」 |
| **〇·1 素材来源** | ① 原创 / ② 改编 / ③ 对标爆款 / ④ 热点速成 | 与 〇·0 正交可组合（如「海外剧+对标爆款」）|
| **A 模型版本** | ① Seedance 2.5 / ② Seedance 2.0 / ③ MiniMax H3 | 三选一 |
| **B 画幅** | 16:9 / 9:16 / 21:9 | — |
| **C 交付形态** | ① 离线看板 / ② md / ③ 两者都交付 | 强制锁，未指定=停下问 |
| **D 段缝衔接** | ① 末帧定格承接 / ② 换机位硬切 / ③ 空镜过渡 / ④ 技巧型转场 | **多段任务四选一，逐项独立弹出，禁止合并** |

**多段任务判定式（唯一口径）**：`目标成片时长 ÷ A 锁单段上限 > 1` 即多段任务（单段上限：Seedance 2.5=30s / 2.0=15s / H3=15s）。判定在立项期完成，**严禁以「还没到分镜」为由推迟 D 锁**。示例：2 分钟片 + Seedance 2.0 → 120÷15=8 段 → 多段任务，D 必锁。

## I 画风锁（导演风格 · 必弹卡锁）

必须推送候选卡让用户勾选，卡内含「按你的推荐走」一项；选定即冻结。**未表态 = 停下询问**，写了默认值也不行。

- 用户回「按你的推荐走」或未指定导演卡（常规稿）→ 只把**美学短语（≤30 字）并入【画幅风格】行**，不写段8/段9。
- 用户明确选了导演卡 → 从风格库取段8【STYLE】+ 段9【PERFORMANCE】成品块**逐字粘贴，禁自创**；交付层零人名（导演/工作室/影片名不进稿）。

## 素材形态（M 轴 · 与锁系统正交）

**本包不持有图**——图由用户在外部平台生成。三档，**每次交付首行必须声明形态**：

- **M0 纯提示词**：稿件内不得出现任何图号。
- **M1 编号占位（默认）**：写图号 + 附《素材接线单》（图号→类型→用途→该挂哪张→不控制什么）。
- **M2 已入库**：可标注已登记。

**四铁律**：不索要图片 · 不因缺图阻塞 · 不写不存在的图号、不声称已核验而实际未核验 · 每次声明形态。

## 赛道附加

- **② 海外剧**：第一句对白前建立【语言与风格合同】（区域/语体/称呼/文化禁区），校准状态逐阶段传递，下游不得自行升级。
- **③ 解说叙事类**：先定子类型（历史人物志/历史事件战役/科普知识解说三选一），脚本=旁白稿 VO；历史/科普题材强制信源分级。
- **④ 其他**（广告/宣传片/PREVIS）：复用全流程，不套剧集专属约定。

**赛道写入基准表后全流程不改；确需改赛道 = 重开任务，禁止中途换道沿用旧产物。**
